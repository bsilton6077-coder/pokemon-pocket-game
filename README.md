# Pokémon Pocket

A simple browser game inspired by Pokémon Pocket card collection.

## Features

- Open booster packs
- Collect cards and build a binder
- Track duplicates and completion progress
- Buy pack upgrades with coins
- Works as a static site and can be hosted on GitHub Pages

## Run locally

Open `index.html` in a browser.

## GitHub Pages

After enabling Pages in the repository settings, use the standard GitHub Pages URL:

`https://bsilton6077-coder.github.io/pokemon-pocket-game/`
